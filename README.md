# Jackie Ng — Personal Profile

Personal website for Jackie Ng, computational structural biologist and founder of AtomBios.

**Live:** https://grasswall.github.io/jackieng-profile/

## Stack

- Static HTML/CSS/JS (no framework)
- Inter font via Google Fonts
- Light/dark mode via `prefers-color-scheme`
- Minimal JS: IntersectionObserver fade-ups only

## Development

Just edit the files:
- `index.html` — page structure
- `styles.css` — all styling
- `main.js` — fade-up animations

Open `index.html` in a browser to preview locally.

## Deploy

Pushes to `main` auto-deploy via GitHub Actions → GitHub Pages.
